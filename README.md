# Línea de Tiempo Interactiva: Palestina/Israel

Una aplicación web interactiva que muestra la evolución histórica de la región de Palestina/Israel desde el 10,000 a.C. hasta el presente.

## 🌟 Características

- **Línea de tiempo horizontal**: Visualización cronológica de los períodos históricos más importantes
- **Interactividad completa**: Haz clic en cualquier período para ver información detallada
- **Marcador del Año 0**: Referencia visual destacada para la transición BCE/CE
- **Diseño responsivo**: Funciona perfectamente en dispositivos móviles y de escritorio
- **Información histórica completa**: Desde las primeras culturas hasta los conflictos contemporáneos
- **Colores diferenciados**: Cada período histórico tiene su propio color distintivo

## 🚀 Cómo usar la aplicación

1. **Visualizar la línea de tiempo**: La aplicación muestra automáticamente todos los períodos históricos
2. **Explorar períodos**: Pasa el ratón sobre las tarjetas para ver efectos visuales
3. **Ver detalles**: Haz clic en cualquier período para ver información detallada debajo
4. **Navegar**: Usa la barra de desplazamiento horizontal para moverte por toda la historia

## 📚 Períodos Históricos Incluidos

La línea de tiempo abarca más de 12,000 años de historia:

- **Paleolítico Superior** (10,000-8,500 a.C.) - Cultura Natufiense
- **Neolítico** (8,500-4,500 a.C.) - Revolución Agrícola
- **Calcolítico** (4,500-3,200 a.C.) - Edad del Cobre
- **Edad del Bronce** (3,200-2,000 a.C.) - Ciudades-Estado Cananeas
- **Patriarcas Bíblicos** (2,000-1,200 a.C.) - Abraham, Isaac, Jacob
- **Edad del Hierro I** (1,200-1,000 a.C.) - Pueblos del Mar y Filisteos
- **Reinos de Israel y Judá** (1,000-586 a.C.) - David y Salomón
- **Exilio Babilónico** (586-539 a.C.) - Destrucción del Primer Templo
- **Período Persa** (539-332 a.C.) - Retorno del Exilio
- **Período Helenístico** (332-63 a.C.) - Alejandro y los Macabeos
- **Período Romano** (63 a.C.-324 d.C.) - Herodes y las Revoltas
- **Período Bizantino** (324-638 d.C.) - Cristianismo Imperial
- **Conquista Árabe** (638-1099 d.C.) - Califatos Omeya y Abasí
- **Cruzadas** (1099-1291 d.C.) - Estados Cruzados
- **Período Mameluco** (1291-1517 d.C.) - Dinastía Ayubí y Mamelucos
- **Imperio Otomano** (1517-1917 d.C.) - 400 años otomanos
- **Mandato Británico** (1917-1948 d.C.) - Declaración Balfour
- **Israel/Palestina** (1948-presente) - Conflicto Contemporáneo
